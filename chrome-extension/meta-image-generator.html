Requested Permissions

  • activeTabRead active page metadata and social image tags for analysis.
  • scriptingRun content scripts to extract Open Graph, Twitter, and standard meta information.
  • <all_urls>Allow checks and generation support across pages you actively open in Chrome.

Analysis runs in your browser context and permissions are used for on-page metadata auditing and generation features.

How to Install

From Chrome Web Store

  1. Open the Chrome Web Store listing.
  2. Click Add to Chrome.
  3. Confirm the installation prompt.
Open Web Store

Manual (Developer Mode)

  1. Clone or download the extension repository.
  2. Open chrome://extensions/ and enable Developer mode.
  3. Click Load unpacked and select the extension folder containing manifest.json.
