Requested Permissions

  • activeTabRead the current page to evaluate content.
  • scriptingRun content scripts for on-page checks.
  • <all_urls>Allow analysis on supported web pages you actively open in Chrome.

All analysis is client-side and uses only required extension permissions.

How to Install

From Chrome Web Store

  1. Open the Chrome Web Store listing.
  2. Click “Add to Chrome”.
  3. Confirm the installation prompt.
Open Web Store

Manual (Developer Mode)

  1. Clone or download the extension repository.
  2. Open chrome://extensions/ and enable Developer mode.
  3. Click “Load unpacked” and select the extension folder containing manifest.json.

Privacy & Data

SEO Checklist does not collect, store, or transmit user data. Every analysis runs locally in your browser and no audit payload is sent to external servers.
